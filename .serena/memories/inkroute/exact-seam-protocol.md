# InkRoute exact seam protocol

Use this when the task already names a file, route, helper, gap row, package script, fixture, static assertion, or CI error seam.

## Default answer

Skip Serena and skip Obsidian. The optimized path is:

1. RTK-read the exact tracker row or file slice.
2. Patch the smallest source, test, tracker, or docs contract.
3. Keep external provider, legal, production, credential, browser, device, and CI proof gates explicit.
4. Report validation as `not run` unless the user explicitly asked for it.

## Gap closure lane

- `GAP_TRACKER.md` row -> owning runtime/readiness file -> static assertion -> package mirror if present -> tracker wording.
- Export named command, control, evidence, artifact, execution-policy, or external-evidence helpers when inline contracts need identity.
- Static tests should assert helper identity with `toBe(...)` before value-shape assertions.
- Do not reopen Obsidian between similar runtime-static rows unless a prior accepted architecture/API decision changes the implementation.

## CI lane

- If the log names a missing dependency, lockfile mismatch, fixture, package script, assertion, or file, patch that seam first.
- Do not turn an exact failing check into a broad repo investigation.
- Use Serena only if the owner file or exported call-site blast radius is unknown after the exact seam is exhausted.

## Stop conditions

- A lookup that will not change the next edited file is rejected.
- Obsidian is rejected for current source, test, tracker, branch, diff, lockfile, or CI truth.
- Tool unavailability, credentials, or noisy results are not blockers; fall back to scoped RTK search and keep moving.

## Report shape

When this protocol is used, the final report should be short:

- Files changed.
- Local seam closed.
- External gates preserved.
- Validation/tests run, or `not run` when not explicitly requested.
