# Handoff Folder

This folder contains copy-ready and machine-readable handoff assets for Codex, Jules, Claude Code, local terminals, and provider-console work.

## Phase 16 additions

- `AGENT_EXECUTION_QUEUE.md` — human-readable prioritized external-agent task list.
- `GAP_CLOSURE_PROTOCOL.md` — evidence rules for closing or downgrading gaps.
- `CODEX_FIRST_RUN_PROMPT.md` — first-run install/build verification prompt.
- `JULES_INFRA_PROMPT.md` — database/auth/storage infrastructure prompt.
- `CLAUDE_PROVIDER_PROMPT.md` — provider sandbox implementation prompt.
- `manifests/agent-execution-queue.json` — machine-readable agent task queue.
- `manifests/gap-audit-report.json` — generated by `scripts/handoff/audit-gap-tracker.mjs`.
- `manifests/phase-documentation-audit.json` — generated by `scripts/handoff/verify-phase-docs.mjs`.

Run dependency-free checks from the repo root:

```bash
node scripts/handoff/verify-phase-docs.mjs
node scripts/handoff/audit-gap-tracker.mjs
node scripts/handoff/print-next-agent-tasks.mjs
```

## Phase 17 additions

Phase 17 adds quality gate docs and scripts under `docs/quality/` and `scripts/quality/`. External agents should run these before changing gap statuses:

```bash
node scripts/quality/audit-doc-links.mjs
node scripts/quality/audit-gap-evidence.mjs
node scripts/quality/print-quality-gates.mjs
```
